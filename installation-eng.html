Install Notes — Fresh Install Only

1 Copy Files

Copy ALL files to your webserver.

2 Import Database

Import via phpMyAdmin the file:

tt.v.3.8.3.by.tt.forum.sql

3 MySQL Connection

Edit backend/mysql.php to suit your MySQL connection.

4 General Configuration

Edit backend/config.php to suit your needs.

Special note should be taken for URLs, emails, and paths. Use check.php if unsure.

5 Remove Safety Line

Remove the following line from config.php:

die("You didn't edit your config correctly.");
You MUST remove this line, otherwise the installation will not work.

7 Run Check

Run check.php from your browser to check you have configured everything ok.

check.php is designed for UNIX systems — if you are using Windows it may not report the paths correctly.

8 Register Administrator

Now register as a new user on the site. The first user registered will become administrator.

9 Remove check.php

If check.php still exists, please remove it or rename it.

A warning will display on the site index until it's removed.

10 Secure Backups

You should properly secure backup-database.php and the backups/ directory (htaccess/htpasswd).

11 Scraper API Keys (IMDb, YouTube, TMDB)

For torrent-details.php to work properly and scrape data from IMDb, YouTube and TMDB, edit backend/TTIMDB.php:

  1. Line #16: 
    private $_nodes = ['https://www.omdbapi.com/?apikey=your_own_omdbapi_key&i=%s'];
  2. Lines #213 and #214: 
    $tmdbApiKey    = "your_own_tmdbapi_key";
$youtubeApiKey = "your_own_youtube_key";

12 Bot Protection (Cloudflare)

To avoid BOT attacks, Cloudflare defense is already built into the signup, login and recovery files, but it is not activated — you need to do it yourself.

Use your own Cloudflare keys in config.php at lines #33 and #34:

$site_config['CLOUDSITEKEY'] = 'YOUR_OWN_CLOUDSITE_KEY';
$site_config['CLOUDSECRET'] = 'YOUR_OWN_CLOUDSECRET_KEY';

13 Alternative torrent-details.php

If you don't like (or it doesn't work for some reason) torrent-details.php, rename it to another name, then rename torrent-details-5.php to torrent-details.php so it works.

For any problems please visit torrenttrader.uk
